# 云台速度模式控制设计

## 意图

将云台控制滑杆改为无单位的速度比例输入，并保证用户释放滑杆后，云台收到明确的零速度停止指令。

## 目标

- 俯仰和航向输入使用 MAVLink angular-rate 模式。
- 两个滑杆显示 `-100%` 到 `+100%` 的控制比例，不显示度数或度/秒。
- `MAV_CMD_DO_MOUNT_CONTROL` 直接承载当前比例映射的速度；不再维护或累积角度目标。
- 速度从非零变为零时，发送一次俯仰、航向均为零的停止指令。

## 非目标

- 不改变云台固件的最大速度、机械限位或串口配置。
- 不提供 Center/归中按钮；滑杆回零是唯一的停止操作。

## 根因

现有代码将滑杆值作为 `deg/s` 累积为角度目标，同时以 `MAV_CMD_DO_MOUNT_CONFIGURE` 参数 6、7 的 `0` 配置俯仰/航向角度输入模式。滑杆回零时没有下发新指令，云台继续追逐最后一次累积的角度目标，因此会持续运动至限位。

## 已考虑的方案

1. 保持角度模式，只在松开时发送当前姿态角：需要可靠姿态回传，且与“云台是速度模式”的实际接口不符。
2. 继续由上位机积分速度为角度目标：仍会产生目标滞后和停止语义问题。
3. 使用 MAVLink angular-rate 模式，直接发送当前速度并在释放时发送零速度：采用此方案，语义与固件的速度模式一致。

## 实现约束

- `MAV_CMD_DO_MOUNT_CONFIGURE` 的参数 6（pitch input）和参数 7（yaw input）必须为 `1`。
- `MAV_CMD_DO_MOUNT_CONTROL` 的参数 1（pitch）和参数 3（yaw）为当前速度指令；参数 7 保持 MAVLink targeting 模式 `2`。
- 速度比例范围固定为 `-100` 至 `+100`。
- 释放任一滑杆后必须立即发布一次当前两轴指令；当两轴均为零时，该指令即为停止命令。
